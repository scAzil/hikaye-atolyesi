# AZiL — Hikâye Atölyesi

Dallanabilen ve etkileşimli hikâyeler oluşturmak için geliştirilmiş AZiL editörü.

**Canlı uygulama:** https://azil-hikaye-atolyesi.chic-cabin-0509.chatgpt.site/

## Özellikler

- Mesajlaşma biçiminde karakter ve sahne düzenleme
- Farklı sonlara ayrılan hikâye akışları, kararlar ve sahne haritası
- Görsel, ses ve diğer medya dosyalarının projelere eklenmesi
- Ön izleme, hata denetimi ve rehber/örnek hikâye
- TXT, ZIP ve bağımsız HTML dışa aktarma/çevrimdışı kullanıma ilişkin seçenekler

## Kaynak ve dağıtım durumu

Bu depo, projeye ayrılmış **resmî GitHub çalışma alanıdır**. Henüz buraya uygulamanın tam kaynak kodu veya gerçek çevrimdışı HTML paketi yüklenmemiştir. GitHub'ın otomatik oluşturduğu **Source code (zip)** dosyası uygulamanın çalışır sürümü değildir.

Çevrimdışı sürümü burada yayımlamadan önce canlı editörden **Çevrimdışı editör** çıktısını indirmek ya da uygulamanın özgün kaynak dosyalarını dışa aktarmak gerekir. Ardından gerçek paket ZIP olarak `Releases` bölümüne eklenebilir.

**Planlanan düzen:**
- `src/`: Mevcut projeden alınmış doğrulanmış kaynak dosyaları
- `docs/`: Kullanım ve proje biçimi rehberi
- `examples/`: Telif hakkı sorunu bulunmayan örnek hikâyeler
- `Releases`: Çevrimdışı çalışan HTML veya paketlenmiş sürümler

**Not:** Canlı uygulama üzerinde yayımlanmış özelliklerin GitHub deposunda da çalıştığı, ilgili kaynaklar gerçekten yüklenip test edilmedikçe iddia edilmez.
