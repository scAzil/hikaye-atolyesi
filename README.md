# AZiL Hikâye Atölyesi

Karakterleri, sahneleri ve seçimlerle dallanan hikâyeleri düzenlemek için geliştirilen etkileşimli hikâye editörü.

**[Hikâye Atölyesi'ni aç](https://azil-hikaye-atolyesi.chic-cabin-0509.chatgpt.site/)**

## Özellikler

- Karakter ve sahnelerle mesajlaşma biçiminde hikâye tasarımı
- Farklı seçimler ve sonlar oluşturma
- Medya dosyaları, sahne haritası ve hikâye ön izlemesi
- Proje yedekleri ve HTML çıktısı üretme

## İndirme durumu

GitHub deposunda henüz uygulamanın tam kaynak kodu veya çevrimdışı HTML dağıtım paketi bulunmuyor. Uygulamayı bağlantıdan açabilirsiniz. Çevrimdışı sürüm için uygulamanın kendi indirme/dışa aktarma işlevi kullanılmalıdır.

GitHub'ın otomatik **Source code (zip)** bağlantısı, tek başına uygulamanın çalışır sürümü değildir.
